# Auditoría de Simulación Warp HFEG-LT v5.0

Este repositorio contiene los datos técnicos y la auditoría analítica del pipeline de simulación **HFEG-LT**, enfocado en la generación de energía negativa mediante el Efecto Casimir Dinámico (DCE) en configuraciones toroidales.

## Hallazgo Principal
La auditoría identificó una discrepancia de **15 órdenes de magnitud** entre los resultados numéricos de la simulación (~10¹⁷ J/m³) y el límite físico estricto de la **Desigualdad Cuántica de Ford-Roman** (183.3 J/m³) para la geometría analizada.

## Contenido
- **Paper Final (PDF):** Análisis completo en formato académico.
- **Datos de Simulación (JSON):** - `HFEG_Quantum_Stability_v50.json`: Parámetros de resonancia y squeezing.
  - `HFEG_Unified_Physics.json`: Lógica de convergencia del pipeline.
